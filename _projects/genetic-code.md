The genetic code is redundant, and that redundancy buffers errors.
A mutation in a codon often still means the same amino acid.
The usual theories of how that happened split in two.
Either the code is frozen, and only the genes evolve, or the code is scored by an information-theory objective, such as channel capacity, that is not the same thing as leaving more offspring.

With Marc Klinger and Nikhil Kunapuli I have been building a population model in which the code and the sequences evolve together.
Selection acts only on the translated phenotype.
Mutation acts on the sequence and, separately, on the code.
Horizontal transfer of genetic material is in the dynamics as well.

In the smallest version, an alphabet of two symbols and two meanings on sequences of length two, selection alone pushes the population onto codes that sit near the rate–distortion tradeoff.
Error buffering shows up because those codes leave more descendants, not because it was written into the objective.
This is a toy alphabet.
It is not the biological code of sixty-four codons and twenty amino acids.
It is a check that the mechanism can work before the model is scaled up.

This work is ongoing.
It is not a submitted paper.
The biological code is a later question, and I do not want the small model to be mistaken for it.
